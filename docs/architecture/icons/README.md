# AWS architecture icons

The five SVGs in this directory are selected, unmodified icons from the July 2026 [AWS Architecture Icon Package](https://aws.amazon.com/architecture/icons/): AWS Cloud, AWS Elastic Beanstalk, Amazon ElastiCache, Amazon EC2, and Amazon S3.

`aws-deployment.py` embeds them in the generated SVG so the diagram renders without network access or an icon library. These icons indicate only the AWS services established by the repository; the custom application, browser, device, GitHub Actions, and Terraform symbols are drawn by the diagram source.
